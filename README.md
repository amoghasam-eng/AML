# Applied Machine Learning - All Experiments

This repository contains a single Google Colab notebook encompassing all 11 experiments conducted for the Applied Machine Learning course.

## Contents
- **Experiments 1-11:** All code, visualizations, and results are organized sequentially within the notebook.
- **Environment:** Developed in Google Colab using Python.

## How to View
1. Open the `ipynb` file in this repository.
2. Click the **"Open in Colab"** button at the top of the notebook to run the code interactively.
